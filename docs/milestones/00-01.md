## Delivered Java foundation

The framework free core provides reduced rational arithmetic, directed decimal intervals, immutable geometry, validated unit domains, four map families, continuous peak membership profiles, representative membership bounds, exact finite fuzzy operations, and verified box trajectories.

The map families are affine contraction, tent, logistic, and coupled tent. Logistic images account for the interior extremum. Exact rational evaluation and the independent affine closed form provide reference calculations.

Finite fuzzy operations preserve maxima at collisions, complete positive alpha cuts, and nonconvex support. The endograph distance includes the complete zero baseline. Approximate states are not automatically normalized.

At this foundation delivery, the implementation contained no adaptive CAE solver, trained policy, API, frontend, or measured algorithmic speedup. Milestone 02 subsequently adds the deterministic adaptive solver.
