# Milestone 02: deterministic certified method

**Delivery date:** 17 November 2026.  
**Scope:** local Java numerical engine, adaptive refinement, replayable evidence, and tests.  
**Research status:** internal P1 to P3 argument connected to code; independent mathematical review and closest full text comparison remain open.

## Delivered

- A deterministic CAE solver for the supported one and two dimensional map and membership families.
- Whole cell membership variation, grade evaluation errors, local Lipschitz propagation, interval image tightening, and grade capped endograph bounds at every requested time.
- Maximum horizon bound refinement, deterministic age ties, configurable periodic FIFO fairness, and a uniform FIFO policy for comparison.
- Immutable best and last complete snapshots, explicit tolerance and resource outcomes, cooperative cancellation, and atomic rollback of incomplete refinements.
- A canonical certificate verifier that reconstructs exact binary partition coverage and recomputes all numerical quantities.
- Seven JSON example runs, a readable Markdown summary, and a separate verification command that reloads saved evidence and repeats the full deterministic trace.

The [method specification](../CAE_METHOD.md) defines the exact formulas, invariants, caveats, and mapping to Java types.

## Evidence and tests

The suite checks exact finite references across all map families and multiple precisions, interval trajectory containment, representative residuals, deterministic complete result equality, fairness, tie breaking, all budget exits, zero and weak profiles, and both initialization and mid refinement failures.

A separate test oracle computes the exact continuous endograph distance of a one dimensional triangular profile against a finite fuzzy state. It enumerates affine intersections over membership segments using Rational values. It does not reuse the CAE certificate formula or sample the domain. A closed form 1/5 distance checks the oracle itself. Affine transported triangles are then checked at every requested time for three arithmetic precisions.

A worked two peak example proves that one split can increase the actual endograph error from 1/2 to 5/8. Both bounds are matched by exact point distance lower witnesses. This supports the incumbent retention behavior independently of any claim about interval conservatism.

Tampering tests reject missing cells, overlapping paths, altered membership and geometry, invented radii, changed aggregate bounds, a mismatched problem or precision, edited operation counters and refinement traces, unsupported map definitions, and JSON numeric values substituted for decimal strings.
