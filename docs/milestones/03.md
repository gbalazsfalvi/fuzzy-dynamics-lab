# Milestone 03: comparison runner and scalar baselines

**Delivery date:** 17 November 2026.  
**Scope:** local exploratory comparison, deterministic policies, exact scalar references, and saved evidence replay.

## Delivered implementation

- Four CAE policies sharing the same certificates and resource rules: uniform FIFO, maximum horizon bound, next step greedy, and predicted gain per estimated work.
- Exact scalar alpha cut propagation with full interval unions, interior extrema, weak components, and singleton cores.
- A vertical quantization certificate for the alpha grid baseline.
- An exact PWL specialization of the published 2021 transport kernel for affine and tent dynamics, with explicit nonlinear and two dimensional exclusions.
- Exact continuous distance from finite states to an alpha grid staircase, including its independent reference error bracket.
- Fixed cut diagnostics with explicit empty mismatch statuses.
- A versioned 16 problem pilot, randomized paired method order, JVM warmup, five timed repetitions, separated verification cost, and full outcome retention.
- Typed manifests, individually hashed numerical artifacts, raw CSV observations, refinement curves, and strict reload and replay.

The [comparison method](../COMPARISON_METHOD.md) specifies every method, reference assumption, timing boundary, and evidence field.

## Research limits

The implementation checks passed 123 JUnit cases (112 core, 11 experiments). The pilot recorded all 192 declared rows: 168 numerical runs and 24 unavailable outcomes. Five timed repetitions produced 840 raw observations. Saved evidence replay verified all 168 numerical runs.

Observed tolerance successes were 25/32 for uniform, 29/32 for maximum bound, 27/32 for next step, and 28/32 for predicted gain. The scalar alpha grid completed all 24 eligible rows, and the exact PWL specialization completed all 16 eligible rows. No numerical failure was observed. All resource exits and exclusions remain in the saved table.

There were 160 independently constructed continuous reference brackets on the preselected scalar reference cohort. None had a verified lower endpoint above its CAE certificate. This is evidence for those tested instances, not a proof of the whole implementation or a joint two dimensional reference result.

Generated results live in artifacts/comparison. The source and protocol hashes in that manifest identify the implementation used for this observed pilot; later source changes require a fresh run or the matching implementation for strict replay.

The source access conditions for milestone 00 remain open for the closest 2007 and 2016 full texts. This milestone reproduces the eligible exact PWL transport specialization, rather than attributing missing nonlinear PSO preprocessing to the authors.

The pilot is exploratory. Final training, validation, in distribution test, and out of distribution test cohorts are separate later deliverables. A final research claim requires that separation, the declared comparisons, and appropriately grouped statistical analysis.

Continuous independent references currently cover scalar cases. Coupled two dimensional CAE runs retain their certificates and exact finite test evidence but do not receive a fabricated continuous reference error.

All source, comments, documentation, and output fields are English. No remote publication or deployment was performed.
