# Milestone 07: study, evidence release and bilingual presentation

## Deliverables and their roles

The English [study source](../../research/report/main.tex) connects the numerical
contract, P1's two directed estimates, the trajectory recurrence, conditional
fixed-horizon convergence, the exact nonmonotone refinement example and the
frozen policy experiment. The exported
[study PDF](https://github.com/gbalazsfalvi/fuzzy-dynamics-lab/releases/download/v0.1.0/fuzzy-dynamics-lab-study.pdf)
is a separately reviewed release asset. It is a research software report, not a
peer-reviewed publication or an independently established novelty claim.

The [complete data archive](https://github.com/gbalazsfalvi/fuzzy-dynamics-lab/releases/download/v0.1.0/fuzzy-dynamics-lab-v0.1.0-data.zip)
contains the complete saved validation and final cohorts, numerical payloads,
analysis, training evidence and frozen inputs. The smaller
[curated evidence archive](https://github.com/gbalazsfalvi/fuzzy-dynamics-lab/releases/download/v0.1.0/fuzzy-dynamics-lab-v0.1.0-evidence.zip)
retains complete outcome summaries but only identifier-selected raw examples.
It cannot support a full numerical replay by itself. Both archives include a
file inventory, SHA-256 checksums and an explicit statement of omissions.

The English and Hungarian portfolio presentations explain the architecture,
measured results and limits for readers who do not run the project:

- Case study: [English](https://balazsfalvi.hu/work/fuzzy-dynamics-lab/) and
  [Hungarian](https://balazsfalvi.hu/hu/munkak/fuzzy-dynamics-lab/).
- Article: [English](https://balazsfalvi.hu/journal/fuzzy-dynamics-lab/) and
  [Hungarian](https://balazsfalvi.hu/hu/naplo/fuzzy-dynamics-lab/).

The portfolio serves static pages, screenshots and downloads. It does not
expose the numerical API. The local workbench remains a loopback application.

## Evidence-to-publication chain

1. Freeze source/build inputs, problem groups, model exports, the executable
   protocol and analysis inputs before final outcomes.
2. Run every declared comparison and retain unavailable methods, resource exits,
   numerical failures, all model seeds and the fixed timing subset.
3. Replay the saved numerical evidence with Java. The replay wrapper records a
   receipt only after observing a successful verifier and matching run count.
4. Admit the exact locked protocol and replay receipt to the unchanged frozen
   analysis. Keep complete tables and all original figures.
5. Import those saved summaries into the study. Derived paper layouts preserve
   every method, regime, effect estimate and unavailable state; their hashes
   record the mapping. They do not recompute statistical estimates.
6. Compile the actual final PDF, render every page and inspect mathematics,
   table/figure readability, clipping, text and links. Layout fixtures remain
   explicitly synthetic and outside all public asset paths.
7. Capture the real packaged workbench and saved-evidence view. Screenshots
   illustrate actual application behavior; they do not establish a performance
   advantage.
8. Review and commit only intended source files. Package existing evidence with
   the actual source revision, verify archive contents/checksums, run CI on the
   public revision and identify the release with a tag.
9. Publish reviewed static portfolio bytes as a versioned release, then verify
   English/Hungarian pages and the served download bytes over real HTTPS.

## Research gates that publication does not close

P1–P3 have documented internal derivation and implementation review, including
disclosed AI assistance. This is not external mathematical peer review. The
closest full-text comparison remains incomplete; the source register
distinguishes complete reads, abstracts, previews and metadata. Scientific
novelty remains **NOT_ESTABLISHED**.

Finite-cohort measurements cannot prove that learning is generally faster.
Conditional work/time effects exclude pairs without two successful positive-cost
runs, while certification tables retain those outcomes. Joint two-dimensional
reference error is unavailable; scalar checks do not fill that gap. Fixed
precision, finite budgets and low-grade component behavior remain explicit in
the study and both portfolio translations.
